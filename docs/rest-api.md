# REST API & OpenAPI Reference

The `apps/api` Fastify server exposes the system over HTTP under the `/api`
prefix. This document is the full endpoint reference. For cross-cutting topics
(auth, CORS, time units, live-vs-durable, errors) see
[api-and-agents.md](./api-and-agents.md).

> The machine-readable contract is generated by `@fastify/swagger` from the
> per-route JSON schemas in `apps/api/src/schemas.ts`.

## Discovering the API

| What | URL |
|---|---|
| OpenAPI 3.1 document (JSON) | `GET /api/openapi.json` |
| Swagger UI (interactive) | `GET /api/docs` |

The OpenAPI doc carries `info`, `servers` (`API_PUBLIC_URL`), tags
(`market-data`, `analysis`, `strategy`, `forward-test`, `backtest`) and an
`apiKey` security scheme (`x-api-key` header).

Point any OpenAPI-aware client or agent at `/api/openapi.json` to auto-generate
typed calls.

## Conventions

- **Auth:** send `x-api-key: <key>` when the server has `API_KEY` set. See
  [auth](./api-and-agents.md#authentication).
- **Time units:** vary by endpoint — see the
  [units table](./api-and-agents.md#time-units-read-this--its-the-1-footgun).
  Noted per-endpoint below.
- **Errors:** `{ error, message, statusCode? }`. Missing required params → `400`.

# 503 { "status": "error", "message": "Database unavailable" }

## Market data

### `GET /api/candles`

Closed OHLCV candles, ascending by time. **Source: Postgres (durable).**

**Query**

| Param | Type | Required | Default | Notes |
|---|---|---|---|---|
| `symbol` | string | ✅ | — | e.g. `BTCUSDT` |
| `timeframe` | enum | ✅ | — | `5m` `15m` `1h` `4h` |
| `limit` | integer | — | `500` | 1–1500 |

**Response** `200` — `Candle[]`

| Field | Type | Notes |
|---|---|---|
| `time` | number | **Unix seconds** |
| `open` `high` `low` `close` | number | |
| `volume` | number | |
| `isClosed` | boolean | always `true` here |

```bash
curl "http://localhost:3001/api/candles?symbol=BTCUSDT&timeframe=5m&limit=2"
```
```json
[
  { "time": 1781685600, "open": 64957.9, "high": 65056.6, "low": 64902.9, "close": 65027.4, "volume": 1100.6, "isClosed": true },
  { "time": 1781685900, "open": 64881.4, "high": 64957.9, "low": 64855.0, "close": 64874.4, "volume": 1215.1, "isClosed": true }
]
```

## Analysis (ICT structure)

All times are **Unix seconds**.

### `GET /api/structure`

Market-structure breaks (MSS + BOS) over the most recent ~300 candles.
**Computed on each call.**

**Query:** `symbol` (req), `timeframe` (req).

**Response** `200` — `StructureBreak[]`

| Field | Type | Notes |
|---|---|---|
| `type` | `"MSS"` \| `"BOS"` | MSS = direction change, BOS = continuation |
| `direction` | `"bullish"` \| `"bearish"` | |
| `breakLevel` | number | price level broken |
| `time` | number | candle that closed through (sec) |
| `fromTime` | number | origin swing time (sec) |

### `GET /api/fvg`

Active fair-value-gap zones for the configured market. **Live / in-memory** —
returns `[]` until the market-data feed has populated zones.

**Query:** `symbol` (req), `timeframe` (req).

**Response** `200` — `FvgZone[]`

| Field | Type | Notes |
|---|---|---|
| `id` | string | `"{direction}-fvg-{time}"` |
| `direction` | `"bullish"` \| `"bearish"` | |
| `fromTime` / `toTime` | number | gap span (sec) |
| `top` / `bottom` | number | price boundaries |
| `status` | `"active"` \| `"mitigated"` | |
| `mitigatedAt` | number? | sec, if mitigated |
| `touched` | boolean? | partial mitigation |
| `touchedAt` | number? | sec, if touched |

### `GET /api/order-blocks`

Order blocks over the most recent ~200 candles. **Computed on each call.**

**Query:** `symbol` (req), `timeframe` (req).

**Response** `200` — `OrderBlock[]`

| Field | Type | Notes |
|---|---|---|
| `id` | string | |
| `direction` | `"bullish"` \| `"bearish"` | |
| `top` / `bottom` | number | boundaries |
| `time` | number | OB candle time (sec) |
| `fromTime` | number | render origin (sec) |
| `status` | `"active"` \| `"breaker"` \| `"broken"` | |
| `breakTime` | number? | when it became a breaker (sec) |
| `useBody` | boolean | body vs wick boundaries |

### `GET /api/liquidity`

Swing-point liquidity levels with swept status. **Computed on each call.**

**Query:** `symbol` (req), `timeframe` (req).

**Response** `200` — `LiquidityLevel[]`

| Field | Type | Notes |
|---|---|---|
| `type` | `"buy-side"` \| `"sell-side"` | buy-side = swing high, sell-side = swing low |
| `price` | number | the level |
| `time` | number | swing time (sec) |
| `swept` | boolean | |
| `sweptAt` | number? | sec, if swept |

## Strategy (live ICT A-Model)

**In-memory / live** — only meaningful while the API has been running and
ingesting the feed.

### `GET /api/signals`

Most recent generated signals.

**Query**

| Param | Type | Required | Default |
|---|---|---|---|
| `symbol` | string | — | all |
| `limit` | integer | — | `20` (1–100) |

**Response** `200` — `StrategySignal[]`

| Field | Type | Notes |
|---|---|---|
| `side` | `"long"` \| `"short"` \| `"none"` | |
| `symbol` / `timeframe` | string | |
| `signalTime` | number | **Unix seconds** |
| `entry` / `stopLoss` / `takeProfit` | number? | present on actionable signals |
| `riskReward` | number? | e.g. `2.0` |
| `reasons` | string[] | natural-language confluence (great agent input) |
| `drawings` | ChartDrawing[] | overlay geometry |
| `metadata` | object? | bias/sweep/mss/entry detail |

### `GET /api/signals/status`

The ICT confluence checklist (bias → sweep → MSS → FVG entry). With `at`, returns
the checklist **as of that historical moment** (bar-replay) instead of live.

**Query**

| Param | Type | Notes |
|---|---|---|
| `symbol` | string? | defaults to the configured market |
| `at` | integer? | **Unix seconds**; compute checklist as of this time |

**Response** `200` — `StrategyStatus`

```json
{
  "bias": "bullish",
  "sweep": { "detected": true, "type": "sell-side", "level": 64850.0 },
  "mss":   { "detected": true, "direction": "bullish", "level": 64980.0 },
  "fvgEntry": { "detected": true, "direction": "bullish", "entry": 64910.0 },
  "lastEvaluatedAt": 1781686000000
}
```

`bias` is `"bullish" | "bearish" | "neutral"`. `lastEvaluatedAt` is **Unix
milliseconds** (or `null` before the first evaluation).

## Forward test (simulated trades)

`entryTime` / `exitTime` / `createdAt` / `updatedAt` are **Unix milliseconds**.

### `GET /api/forward-trades`

List trades + running account balance. **Durable (Postgres).**

**Query**

| Param | Type | Notes |
|---|---|---|
| `status` | enum? | `pending` `active` `closed_win` `closed_loss` `closed_breakeven` `closed_manual` `cancelled` `expired` |
| `symbol` | string? | |
| `side` | `"long"` \| `"short"`? | |
| `limit` | integer? | `100` (1–500) |

**Response** `200`

```json
{ "trades": [ /* ForwardTrade[] */ ], "count": 12, "balance": 10240.55 }
```

**`ForwardTrade`** key fields: `id`, `signalId`, `strategyName`,
`strategyVersion`, `exchange`, `symbol`, `side`, `status`, `entryTime?` (ms),
`entryPrice?`, `stopLoss`, `takeProfit`, `exitTime?` (ms), `exitPrice?`,
`exitReason?` (`tp` \| `sl` \| `timeout` \| `manual` \| `cancelled`),
`riskAmount`, `positionSize`, `pnl?`, `pnlPercent?`, `rrResult?`, `metadata?`,
`createdAt` (ms), `updatedAt` (ms).

### `GET /api/forward-trades/:id`

Single trade by id. `404` if not found.

### `POST /api/forward-trades/:id/manual-close` *(mutating)*

Close an active trade at a given price.

**Body:** `{ "currentPrice": number }` (required).
Returns the closed `ForwardTrade`. `400` if not active, `404` if missing.

### `POST /api/forward-trades/:id/cancel` *(mutating)*

Cancel a pending trade. Returns the cancelled `ForwardTrade`.
`400` if not pending, `404` if missing.

## Backtest

Result times (`startTime`, `endTime`, replay `candles[].time`) are **Unix ms**.

### `POST /api/backtest/run`

Runs the ICT A-Model through the exact forward-test engine over a window,
auto-fetching missing candles. **Durable** (writes a backtest record).

**Body**

| Field | Type | Required | Default |
|---|---|---|---|
| `startDate` | string (ISO) | ✅ | — |
| `endDate` | string (ISO) | ✅ | — (must be after `startDate`) |
| `symbol` | string | — | `BTCUSDT` |
| `initialBalance` | number | — | `10000` |
| `riskPerTradePercent` | number | — | `1` |
| `feePercent` | number | — | `0.04` |
| `slippagePercent` | number | — | `0.02` |
| `maxOpenTrades` | integer | — | `1` |
| `maxTradesPerDay` | integer | — | `3` |
| `minRiskReward` | number | — | `2` |
| `tradeTimeoutCandles` | integer | — | `24` |
| `maxLeverage` | number | — | `10` |

**Response** `200`

```json
{ "id": "42", "metrics": { /* BacktestMetrics */ } }
```

**`BacktestMetrics`**: `totalTrades`, `wins`, `losses`, `breakeven`, `winRate`,
`profitFactor` (**`number | null`** — `null` = wins with zero losses, i.e.
infinite), `netPnl`, `maxDrawdown`, `maxDrawdownPercent`, `averageRR`,
`averageDurationCandles`, `bestTrade`, `worstTrade`.

```bash
curl -X POST http://localhost:3001/api/backtest/run \
  -H 'content-type: application/json' \
  -d '{"startDate":"2024-01-01","endDate":"2024-02-01","symbol":"BTCUSDT"}'
```

### `GET /api/backtest/results`

List recent backtest summaries (`BacktestSummary[]`): `id`, `symbol`,
`startTime` (ms), `endTime` (ms), `tradeCount`, `netPnl`, `winRate`,
`createdAt` (ms).

### `GET /api/backtest/results/:id`

Full result: `config`, `trades[]`, `metrics`, `equityCurve[]`, and replay
`candles[]` (`time` in **ms**) attached on retrieval. `404` if not found.

## Implementation notes

- Per-route schemas: `apps/api/src/schemas.ts`. Response schemas are kept loose
  (only `/candles` declares a strict response) so Fastify's serializer never
  strips fields a consumer needs.
- Swagger/OpenAPI plugin: `apps/api/src/plugins/openapi.ts`.
- CORS + API-key gate: `apps/api/src/plugins/security.ts`.
- Adding an endpoint: register the route, attach a `schema` (tags + querystring/
  body + descriptions), and it appears in `/api/openapi.json` automatically.
